Design a Zero Trust architecture for a 200-person fintech startup that is cloud-native on AWS. They use Okta for identity, have a Kubernetes cluster (EKS) running microservices, use RDS PostgreSQL and S3 for data, and need to achieve SOC 2 Type II compliance within 6 months. They currently use VPN for remote access and have no micro-segmentation.

Requirements:
1. Design document following the architecture design template
2. Mermaid diagrams for architecture and data flows
3. Migration plan with phases (0-6 months for SOC 2 readiness)
4. Component inventory with technology choices
5. Risk assessment with mitigations
6. CISA ZTMM target maturity stages per pillar
